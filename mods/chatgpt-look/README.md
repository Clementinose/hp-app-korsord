# chatgpt-look

En theme-mod för Claude Code (Code-fliken i Claude-appen på datorn, eller `claude` i terminalen) som ger chatten ett rent, neutralt utseende i ChatGPT-stil:

- Sans-serif-typsnitt, 16 pt med luftigt radavstånd (28 pt)
- Vit/ljusgrå bakgrund i ljust läge, kolgrå (#171717 / #212121) i mörkt läge
- Dina meddelanden i en mjuk, grå, rundad bubbla; Claudes svar som ren text
- Grön accentfärg (#10a37f)

## Ladda den

Från repots rot på datorn:

```
claude --plugin-dir mods/chatgpt-look
```

Utseendet syns i desktop- och mobilappen; terminalen ritar inga teman. Om ditt tillgänglighetstypsnitt eller "högre kontrast" är på vinner de över temat.
